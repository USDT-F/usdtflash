Installation

Multiple ways to integrate USDT-FLASH into your application.

Web Integration

Direct integration via our web interface

<script src="https://cdn.usdt-flash.com/v1/sdk.js"></script> <script> USDTFlash.init({ publicKey: 'pk_live_...', theme: 'dark' }); </script>

API Integration

RESTful API for backend integration

curl -X POST https://api.usdt-flash.com/v1/transactions \ -H "Authorization: Bearer sk_live_..." \ -H "Content-Type: application/json" \ -d '{ "amount": 500, "package": "essential", "wallet_address": "0x..." }'

All API requests must include a valid API key in the Authorization header.
