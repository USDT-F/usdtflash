🔍 مشكلات أمنية إضافية — مراجعة يدوية
متوسط localStorage بدون تشفير — بيانات المستخدم مكشوفة
يتم تخزين بيانات المستخدم currentUser في localStorage بنص صريح بدون أي تشفير. أي سكريبت خارجي أو امتداد متصفح يمكنه قراءة هذه البيانات بسهولة.
💡 الحل: استخدم sessionStorage بدلاً من localStorage، أو قم بتشفير البيانات قبل تخزينها.
متوسط CSP (Content Security Policy) غير مكتملة
الـ CSP الموجودة تحتوي فقط على upgrade-insecure-requests وهي غير كافية. لا يوجد تقييد على مصادر السكريبتات أو الصور أو الخطوط الخارجية، مما يفتح الباب لهجمات XSS.
💡 الحل: أضف سياسة CSP شاملة تحدد المصادر المسموح بها: script-src, style-src, img-src, font-src.
منخفض زر الدعم العائم — يفتح في تبويب جديد بدون rel
الزر العائم الذي تمت إضافته مؤخراً يستخدم target="_blank" بدون rel="noopener noreferrer".
💡 الحل: أضف rel="noopener noreferrer" للرابط العائم.
⚡ مشكلات الأداء
متوسط تحميل مكتبات CSS/JS ضخمة من CDN بدون تأجيل
يتم تحميل Tailwind CSS و Font Awesome و Tabler Icons و Material Symbols في الـ <head> بشكل متزامن مما يبطئ أول رسم للصفحة (First Contentful Paint). حجم هذه المكتبات مجتمعةً يتجاوز 2MB.
💡 الحل: أضف media="print" onload="this.media='all'" للـ CSS غير الحرجة، واستخدم defer للـ JS.
متوسط فيديو Hero يُحمَّل بدون lazy loading
الفيديو في قسم Hero يبدأ التحميل فوراً حتى لو كان المستخدم على اتصال بطيء. لا يوجد fallback مناسب للمتصفحات القديمة.
💡 الحل: أضف preload="none" أو preload="metadata" للفيديو، وتأكد من وجود poster image.
منخفض صور خارجية من CoinGecko بدون أبعاد محددة
الصور المحملة من assets.coingecko.com لا تحتوي على width و height صريحين مما يسبب Cumulative Layout Shift (CLS) ويؤثر على نقاط Core Web Vitals.
💡 الحل: أضف width="38" height="38" لكل صورة خارجية.
منخفض Inline styles مكررة بشكل مفرط
الصفحة تحتوي على آلاف الـ inline styles المكررة (مثل style="color:#94a3b8") بدلاً من استخدام CSS classes. هذا يزيد حجم الصفحة ويصعّب الصيانة.
💡 الحل: استخرج الأنماط المتكررة إلى CSS classes في ملف خارجي.
🧹 جودة الكود
متوسط كود HTML ضخم جداً في ملف واحد (+5000 سطر)
الصفحة تحتوي على أكثر من 5000 سطر في ملف HTML واحد يجمع بين HTML وCSS وJavaScript. هذا يجعل الصيانة صعبة جداً ويبطئ تحميل الصفحة.
💡 الحل: قسّم الكود إلى ملفات منفصلة: style.css، main.js، وملفات HTML جزئية.
منخفض كود JavaScript معطّل (dead code) — فرع if(false)
يوجد في الكود فرع if (false) { ... } يحتوي على كود لن يُنفَّذ أبداً. هذا يشير إلى كود قديم لم يُحذف.
💡 الحل: احذف الكود الميت داخل if (false) لتنظيف الملف.
منخفض إمكانية الوصول (Accessibility) — نقص في ARIA labels
أزرار القائمة المتنقلة وزر الإعدادات وزر الدعم العائم لا تحتوي على aria-label مناسب، مما يجعل الموقع غير قابل للاستخدام لمستخدمي قارئات الشاشة.
💡 الحل: أضف aria-label="فتح القائمة" لكل زر تفاعلي بدون نص ظاهر.
