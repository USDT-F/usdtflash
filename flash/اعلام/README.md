## علم مفقود:

⚠️ 🇮🇳 علم الهند (हिन्दी) - **مطلوب إضافته**

## كيفية إضافة علم الهند:

1. قم بتحميل صورة علم الهند (PNG أو WEBP)
2. قم بتسمية الملف: `🇮🇳.png` أو `🇮🇳.webp`
3. ضع الملف في مجلد: `C:\Users\ECC\Desktop\flash\اعلام\`
4. قم بتحديث ملف `css/language-flags.css` السطر الخاص بـ `.flag-in`

### البديل الحالي:
حالياً يتم استخدام علم مصمم بـ CSS (برتقالي، أبيض، أخضر) كبديل مؤقت.

## المسار المستخدم في الكود:

```css
.flag-gb { background-image: url('../اعلام/🇬🇧.webp'); }
.flag-sa { background-image: url('../اعلام/🇸🇦.webp'); }
.flag-fr { background-image: url('../اعلام/🇫🇷.png'); }
.flag-in { /* مطلوب إضافة علم الهند */ }
.flag-jp { background-image: url('../اعلام/🇯🇵.png'); }
.flag-ru { background-image: url('../اعلام/🇷🇺.png'); }
```
